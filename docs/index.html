⛺ 캠핑장 예약 통합 조회

전국 국공립·사설 캠핑장 -곳 · 기간을 고르면 예약 가능한 캠핑장과 사이트, 기간 요금, 크기, 장단점을 보여줍니다.

데이터 불러오는 중…

상태 설명 — 예약가능: 선택 기간 전체 예약 가능한 사이트가 1개 이상 · 만실: 기간 내 빈 사이트 없음 · 직접확인: 온라인 예약은 있으나 자동 조회 미지원 · 캠핏 차단: 캠핏이 자동 조회를 차단해 링크만 제공 · 카페예약·전화예약·현장선착순·운영종료: 온라인 달력 없음 · 조회오류: 플랫폼 응답 실패.

요금은 각 플랫폼 응답값을 우선 표시하며, 없으면 시트의 주말/주중 요금(금·토·공휴일 전날=주말)으로 추정합니다. 실제 결제 금액과 다를 수 있습니다.
